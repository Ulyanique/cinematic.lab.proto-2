# Янтарный Циркуль — интро

Кинематографическое WebGL-интро (three.js + шейдеры): золотая эмблема, 3D-буквы названия, частицы, bloom,
синтезированный саунд-дизайн и покадровый экспорт видео.

## Запуск

```sh
npm ci
npm run dev      # разработка
npm run build    # сборка в один dist/index.html
```

Управление: `Пробел`/`R` — повтор, `M` — звук, `F` — во весь экран, клик по полосе внизу — перемотка.
`?t=4.6` в адресе замораживает кадр на указанной секунде (удобно для отладки).

## Таймлайн (13,6 с)

| Время | Событие |
|---|---|
| 0.2–1.5 | **Пролог:** искра → линия света на всю ширину (анаморфный шлейф) |
| 1.0–2.8 | «Щель» раскрывается в cinemascope; фокус-пулл из мягкого боке |
| 1.6–4.5 | Рой частиц собирается в эмблему, нарастание звука |
| 4.5 | **Удар:** вспышка, толчок и дрожь камеры, ударная волна-линза, хроматика, кадр раскрывается до 16:9 |
| 5.75–7.0 | Буквы названия прилетают, каждая — нота пентатоники |
| 8.0–10.5 | Разделители, подзаголовок, дата |
| 10.9–12.6 | Финальный блик по названию |

## Что добавлено в этой версии

- Новый пролог и «дорогие» эффекты в финальном пассе (`shaders.ts → finalPass`): щель-диафрагма, линия-зажигание,
  фокус-пулл с боке, шоквейв, хроматическая аберрация на ударе, импульс экспозиции.
- Саунд-дизайн (`audio.ts`): партитура синтезируется офлайн детерминированно и синхронна с таймлайном; включается кнопкой «Звук».
- Звук добавляется и в экспортируемое видео (AAC/Opus — что доступно в браузере).
- Перематываемый таймлайн с главами и счётчиком времени.
- Разрешение превью до 1920 px и DPR до 2 (раньше 1280 px и DPR 1) с адаптивным снижением на слабых GPU.
- SVG-иконки вместо символов, которые не отображались в некоторых шрифтах; удалены неиспользуемые шрифты.

## Экспорт

«Создать видео» рендерит сцену покадрово в 1920×1080, 30 кадров/с, 408 кадра, независимо от частоты обновления экрана.
Требуется WebCodecs (Chrome/Edge, HTTPS или localhost). H.264/MP4, при отсутствии — VP9/VP8 в WebM.
