# Янтарный Циркуль — интро

## Запуск

```sh
npm ci
npm run dev
```

Для промышленной сборки: `npm run build`.

## Экспорт

Нажмите «Создать видео». Сцена рендерится покадрово в 1920×1080, 30 кадров/с, без привязки к частоте обновления экрана: 408 кадров на 13,6 секунды. Обработка может идти медленнее реального времени. Готовое видео отображается на странице и доступно для скачивания. Звук не добавляется.

Экспорт использует WebCodecs и требует поддерживаемого браузера в безопасном контексте (HTTPS или localhost). При доступности H.264 сохраняется MP4, иначе — WebM с VP9 или VP8. При отсутствии подходящего кодировщика приложение покажет сообщение; запись в реальном времени, которая может пропускать кадры, не используется.
