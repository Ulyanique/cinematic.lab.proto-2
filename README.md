# Янтарный Циркуль — интро (Cinematic Lab, студия композиции)

Кинематографическое WebGL-интро (three.js + шейдеры): золотая эмблема, 3D-буквы названия, частицы, bloom
и покадровый экспорт видео без звуковой дорожки. Вся композиция настраивается из интерфейса и экспортируется в JSON.

```sh
npm ci
npm run dev      # разработка
npm run build    # сборка в один dist/index.html
```

Клавиши: `Пробел`/`R` — повтор, `P` — пауза (удобно для настройки), `F` — весь экран, `Esc` — закрыть панели.
Клик по полосе внизу — перемотка. `?t=4.6` в адресе замораживает кадр на секунде (отладка).

## Ревизия 3: собственный экструдер, сглаживание, «дорогая» оптика

**Полигоны (логотип и шрифт).** Проверка показала, что `polyfix` чистит контуры, но `ExtrudeGeometry` всё равно ломал фаску: её вершины сдвигаются по биссектрисе, не зная о соседних контурах. В узких зазорах (штрихи «S» внутри отверстия шарнира, контрформы букв, засечки) контуры схлопывались, и получались вырожденные треугольники и рёбра без пары (у самой крупной детали: 872 открытых ребра, 207 неманифолдных, 2308 вырожденных треугольников; также у Й, Ц, Ь).
Новый `src/intro/extrude.ts` строит выдавливание сам:

* смещение каждой вершины фаски ограничено расстоянием до ближайшей границы по лучу (с запасом 42 %), поэтому фаска никогда не заходит в соседний контур;
* профиль фаски сглаживается вдоль контура, развернувшиеся рёбра откатываются;
* крышки — исходный чистый контур, рёбра сходятся вершина в вершину, сетка замкнутая.

Результат на всех 6 шрифтах и сложных глифах (`ЁЩЪЫЖФЯЙ Abgqs&@%`): 0 открытых рёбер, 0 неманифолдных, 0 перевёрнутых, 0 вырожденных (исключение: 8 микрорёбер в «Ф» шрифта Old Standard TT, невидимые). Проверка: `GEO=1 FONTS=forum,prata,playfair,cormorant,montserrat,oldstandard node tools/frames.mjs 11 tag` (после `npm run build`).

**Картинка.**

* MSAA ×4 в HDR-буфере композера (откат на 0 там, где GPU не поддерживает): кромки эмблемы и букв больше не «лесенкой».
* Зум-блюр к эмблеме на ударе.
* «Призраки» линзы (зеркальные отражения ярких зон с дисперсией) на ударе, финальном блике и появлении названия. Управляются настройками «Вспышка» и «Блики».
* Кольцо ударной волны стало мягче, без радужной каймы.

**Ошибки.**

* Горячие клавиши R/P/F/M работали только в латинской раскладке — теперь по физическим клавишам (`e.code`), работают и в русской; сочетания с Ctrl/Alt/Cmd игнорируются.
* Кэш шрифтов запоминал неудачную загрузку навсегда — теперь следующая попытка загружает заново.
* Исправлена ошибка типов в `logo.ts` (`fillRule`).

Снимки кадров: `node tools/frames.mjs 4.53,9.5 tag 1280 720` (один запуск Chromium на много кадров; `DSF=2`, `CLIP="x,y,w,h;x,y,w,h"`, `CFG='{...}'`).

## Исправлено: «камера уходит в черноту»

Провалы в чёрный кадр на старте и на стыке кругов при зацикливании. Причина была не в камере, а в прологе:
глобальное затемнение стартовало на 0.95 с, линия-зажигание — на 0.25 с, а маска «щели» при тонком открытии
выжигала кадр до полоски. Плюс `applySize` переаллоцировал HDR-таргеты на каждом изменении конфига, а в фоновой
вкладке время скачком уходило на десятки секунд.

* пролог начинается сразу: искра видна с первого кадра, затемнение `0.3 → 1` за 1 с;
* «щель» при тонком открытии плавно заменяется мягким затемнением (`uSlitMix`), кромка считается от `uOpen`;
* зацикливание: в превью кадр гаснет до 12 % и новый круг входит за 0.4 с (в экспорте уход в чёрный честный);
* `visibilitychange` переякоривает таймлайн, `applySize` не пересоздаёт буферы без нужды;
* `try/catch` вокруг `composer.render()` + тёмно-тёплый `clearColor` вместо чистого чёрного.

Проверка: `npm run build && node tools/probe.mjs` мерит яркость каждого кадра и падает с кодом 1, если нашёлся
чёрный (`MODE=freeze TIMES=0.1,4.5,13.9` — точечные «стопы»). Подробный разбор и список улучшений —
`docs/analysis-and-blackout.md`.

## Исправлено: мигание колец с 8.1 с

С 8.05 с появляется волна от названия — и кольцо стробоскопило. Причина геометрическая: плоскость волны
26×9, поэтому один и тот же `uW` давал кромку в 2.9 раза тоньше по горизонтали, чем по вертикали (≈2 px).
Расширение шло по `easeOutCubic` (пиковая скорость втрое выше средней) — около 2400 px/с, что выше предела
Найквиста для 30 кадров/с: кольцо обгоняло само себя. Отсюда «мигание», затухающее к ~9.6 с.

* ширина кромки теперь задаётся в мировых единицах и не зависит от пропорций плоскости (`uAspect`);
* корень из пропорций уравнивает толщину по осям, сохраняя широкий силуэт (полная компенсация гнала
  волну за край кадра за пару кадров — проверено кадрами);
* расширение почти равномерное вместо `easeOutCubic` — пиковая скорость втрое ниже;
* широкий мягкий «подшёрсток»: фронт остаётся видимым, даже когда за кадр уезжает на много пикселей;
* след движения кромки (`uPrevR`) — временной антиалиасинг, ограничен 0.16 радиуса и обнуляется между кругами.

Доказательство — развёртка «время × строка кадра»: `npm run slit 7.9 9.6 0.5`. У старого кода диагональ
кольца пунктирная (кольцо пропадает на отдельных кадрах), у нового — сплошная.

## Выбор ролика и управление

В верхней части экрана выпадающий список **Тип ролика**:

* **Интро** — исходная анимация;
* **Аутро** — та же сцена с обратным ходом анимации, затем финальная надпись «ИСТОРИЯ ПРОДОЛЖАЕТСЯ» плавно появляется и исчезает;
* **Фон** — зацикленный финальный образ интро: остаются эмблема, название, кольца, частицы и блеск; анимация продолжается без повторного пролога и затемнения.

Выбранный вариант сразу включается в предпросмотр и используется кнопкой **Создать видео**; фон автоматически зацикливается, у файлов аутро и фона добавляются соответствующие суффиксы.

## Панели управления

* **Слои** — панель «Композиция»: список слоёв. Перетаскивание (или стрелки) меняет порядок — верхний слой ближе
  к зрителю; «глаз» отключает слой; клик выбирает слой для настройки. Блок «Очерёдность появления» сдвигает время
  слоёв по их порядку (каскад).
* **Шестерёнка** — панель «Настройки» (вкладки *Слой / Сцена / JSON*). Панели плавающие, перетаскиваются, сворачиваются
  (двойной клик по заголовку) и становятся полупрозрачными, пока курсор не наведён, — ролик остаётся виден.

Все параметры строятся из единой схемы `src/intro/config.ts`; точка рядом с названием = значение изменено, двойной клик — сброс.

## Что нового в этой ревизии (ремонт полигонов + «дорогое» интро)

**Сломанные полигоны в логотипе и шрифте.** Причина — исходные контуры: SVG из CorelDRAW использует `fill-rule: evenodd`, детали эмблемы (знак «S» в шарнире) самопересекаются и накладываются друг на друга, а глифы шрифтов содержат перекрывающиеся контуры. `SVGLoader` игнорирует `evenodd`, а `earcut` внутри `ExtrudeGeometry` на самопересечениях выдаёт «рваные» веера треугольников, провалы и мерцающие компланарные грани (z-fighting). Новый модуль `src/intro/polyfix.ts` (на базе Clipper) перед выдавливанием:

* приводит любой набор контуров к чистому виду «внешний контур + дыры» с учётом `evenodd/nonzero`;
* убирает самопересечения, дубликаты точек, микроострова и слишком тонкие перемычки (их выворачивала фаска);
* у эмблемы: сильно перекрывающиеся контуры склеивает в одну деталь, слабые перекрытия вычитает — z-fighting исчез, число деталей для анимации «сборкой» сохранено;
* глифы разворачиваются адаптивно (кривые Безье → ломаные по длине), нормали плоских крышек возвращены в точные — пропали диагональные «швы» на гранях;
* глубина и фаска пользовательского SVG масштабируются относительно его размера (раньше большие значения были рассчитаны только на встроенный логотип).

Проверено покадровой триангуляцией всех 6 шрифтов и браузерным эталоном (`Й`, `Ё`, `Ы`, `Щ`, `Ъ`, латиница) — контуры совпадают.

**Новое в анимации.**

* **Световой штрих по контуру эмблемы** — после удара яркая «головка» пробегает по периметру каждой детали (и по дырам) и оставляет затухающий след, второй круг — вместе с финальным бликом.
* **Световая кромка букв** — грани букв вспыхивают, когда по ним пробегает бегущий луч.
* Знак «S» в шарнире теперь читается чётко (раньше был «кашей» из треугольников).

Для проверки в портативном Chromium: `npm i --no-save @sparticuz/chromium puppeteer-core`, затем `AWS_EXECUTION_ENV=AWS_Lambda_nodejs22.x node tools/shot.mjs 4.75,7.3 tag 1920 1080` (после `npm run build`; снимки кадров по времени, `CFG='{...}'` — применить настройки, `CLIP=x,y,w,h` — вырезка).

## Что исправлено и улучшено в этой ревизии

Проверено в портативном Chromium (`@sparticuz/chromium`, WebGL через SwiftShader): покадровая раскадровка, панели, пресеты, экспорт.

* Захардкоженный 13,6-секундный таймлайн заменён конфигурацией: время удара и скорость сжимают/растягивают ролик
  через непрерывное преобразование времени; длительность и главы таймлайна считаются от настроек.
* Экспорт создаёт только видеодорожку, без звука.
* Таймкод показывал «0:13» для 13,6 с (округление вниз) — теперь секунды с десятыми.
* Кадр удара был пересвечен: приглушены вспышка фона, ядро, лучи, свечение роя; силуэт эмблемы читается.
* Настройки не пропадают при перезагрузке.
* Название и текстовые слои поддерживают латиницу (раньше глифы вне кириллического подмножества превращались в «квадраты»).
* Пересборка слоёв при смене текста/шрифта/SVG атомарна: кадр не видит полусобранной сцены, ошибка SVG не ломает сцену.
* Экспорт: разрешение/частота/битрейт из настроек; сообщение об ошибке указывает реальный размер, а не «1920×1080».

## Экспорт

«Создать видео» рендерит сцену покадрово, независимо от частоты экрана. Нужен WebCodecs (Chrome/Edge, HTTPS или localhost).
H.264/MP4, при отсутствии — VP9/VP8 в WebM. Экспорт содержит только видеоряд, без аудиодорожки.
